MakhnoYMMod 2.2.3 — быстрая установка из готовых артефактов
============================================================

Windows — инсталлером (рекомендуется):
  1. Запустите MakhnoYMMod-Setup-2.2.3-win-x64.exe.
  2. «Далее → Установить → Готово»: клиент Яндекс Музыки 5.128.0 ставится
     с уже встроенным модом в %LOCALAPPDATA%\Programs\MakhnoYMMod,
     права администратора не нужны. Ярлыки — рабочий стол и «Пуск»,
     деинсталляция — через «Параметры → Приложения».
  3. Для загрузки треков: winget install ffmpeg
  4. Запустите приложение. В меню мода версия должна показать v2.2.3.

Windows — вручную (замена app.asar):
  1. Закройте Яндекс Музыку.
  2. В каталоге установки откройте resources\.
  3. Сохраните старый app.asar (по желанию).
  4. Замените app.asar файлом MakhnoYMMod-2.2.3-windows-5.128.0-app.asar
     (переименуйте его в app.asar).
  5. Удалите каталог app.asar.unpacked (ffmpeg 79 МБ больше не нужен).
  6. Для загрузки треков: winget install ffmpeg
  7. Запустите приложение. В меню мода версия должна показать v2.2.3.

Linux (Ubuntu 22.04+/Debian 11+):
  sudo apt install ./makhnoymod_5.128.0-r22145392+makhno2.2.3_amd64.deb
  Для загрузки треков нужен системный ffmpeg: sudo apt install ffmpeg

Патчер (для своих сборок клиента):
  Linux:   ./makhno-patcher-linux-amd64 patch --app-dir <каталог|.deb|.exe|.asar>
  Windows: makhno-patcher-windows-amd64.exe patch --app-dir <каталог|.exe|.asar>
  Проверка: ... verify --target <app.asar | каталог | .deb>
  .exe требует 7-Zip в PATH; .deb требует ar/tar/xz.

Исходники: MakhnoYMMod-src-2.2.3.zip (README.md внутри).

Что нового в 2.2.3:
  - Починен патч .exe-инсталляторов (7-Zip вызывался с неверными аргументами,
    внутренний app-64.7z не находился в $PLUGINSDIR).
  - Скачивание треков: ffmpeg больше не перекодирует файл (была потеря
    качества), битые полускачанные файлы не остаются в папке при сбое.
  - Консольные окна ffmpeg на Windows больше не мигают (windowsHide).
  - Повторный патч deb не удваивает суффикс версии; md5sums в deb честные;
    бэкап app.asar.orig не пакуется в deb (пакет похудел на ~15 МБ).
  - Discord RPC: без спама clearActivity и без утечек при реконнектах.
  - Клиент обновлён до 5.128.0 (Linux deb + Windows asar + инсталлер).
  - Новый Windows-инсталлер «всё в одном»: официальный клиент 5.128.0 + мод.
